# New app kickoff (first hour)

1. [ ] `SPEC.md` written from `templates/SPEC.md`; consequential questions asked in one batch.
2. [ ] Stack chosen with a short decision record (`skills/architecture-and-stack`).
3. [ ] Current setup commands checked in official docs (`skills/current-docs-lookup`).
4. [ ] Scaffolded with the official generator.
5. [ ] Lint, format, typecheck, unit tests, E2E runner, `.gitignore`, `.env.example`, README in place.
6. [ ] CI workflow runs install → lint → typecheck → test → build (→ e2e).
7. [ ] First commit green.
8. [ ] `PLAN.md` written; first task is a walking skeleton.
